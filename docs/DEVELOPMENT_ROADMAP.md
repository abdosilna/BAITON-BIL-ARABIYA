# خارطة طريق التطوير — بايتون بالعربية

## المرحلة 1 (مكتملة — Local Demo Mode)
- بناء المعمارية الكاملة وفصل الخدمات عبر Adapters.
- إنشاء الصفحات الـ 16 كاملةً بواجهة عربية RTL احترافية.
- تشغيل Python داخل المتصفح عبر Pyodide Web Worker + CodeMirror 6.
- توفير 13 مستوى تعليمي (Level 0 - 12) + 8 أنماط تمارين + 6 مشاريع باختبارات آلية.
- توفير المعلم الذكي التجريبي (`MockAIProvider`) بـ 4 أوضاع + قراءة صوتية (`SpeechService`).

## المرحلة 2 (ربط الخدمات السحابية)
1. ربط **Supabase** (PostgreSQL + Auth + RLS) عبر تفعيل `SupabaseAdapter` و `SupabaseAuthAdapter`.
2. ربط مزودي الذكاء الاصطناعي (**Gemini** / **OpenAI**) عبر مسارات Backend Proxy آمنة.
3. توسيع بنك الدروس والتمارين وإضافة اختبارات المشاريع المتقدمة.
4. إضافة دعم Speech Recognition الصوتي المتكامل.
